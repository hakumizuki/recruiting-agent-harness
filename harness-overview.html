採用担当アシスタントのハーネス構成

モデルは最後まで同じ安いオープンモデル（ai& の zai-org/glm-5.3-flash）。変えているのはハーネスだけ。

全体構成どのファイルが何をしているか

モデルは「何をしたいか」を tool_use で言うだけ。実際に世界（world.py）を変えるかどうかは、ハーネスが決める。

1回のツール呼び出しが通る道harness.py: Session.process → Session.policy

ハーネスOFFのときは、読み取り以外も含めて全部「実行」に直行する（policy が "allow", "ハーネスOFF: チェックなしで実行" を返す）。

ハーネスの部品

部品何をするかどこにあるか
エージェントループモデルを呼ぶ → tool_use を1つずつ処理 → tool_result を返す、を finish まで最大30回。黙ったら「続けて」と促す。harness.py: Session.process
権限レイヤー全ツール呼び出しを 許可 / 自動 / 確認待ち / ブロック / 差し戻し に振り分ける。判断と理由は必ず画面に出す。harness.py: Session.policy
ガードLINEを送る前に、学生の最新メッセージに辞退の兆候があるかを別のモデル呼び出しで判定。「夜分のお詫び」「事務的な質問」などは兆候ではない、と例示。モデル出力が壊れたらキーワード判定に落とす。harness.py: guard_check
GUARD_SYSTEM / RISK_WORDS
検証申し送りに面接官が知るべき懸念点（他社の選考、勤務地、転勤）が書かれているかを確認し、なければ差し戻す。finish 時に、最終面接すべてに申し送りがあるかも確認。harness.py: Session.policy / process
world.py: MUST_MENTION
学習人が承認した返信について、学生メッセージの種類を固定4分類（服装・持ち物 / 日時・集合場所 / 書類 / その他）で判定し、ルールとして覚える。次回、同じ種類でガードを通ったものは自動で送る。ガードは常にルールより先。harness.py: LearnSession
classify / CATEGORIES
可視化すべての動きを emit でイベント化し、SSE で画面へ流す。harness.py: self.emit
server.py: /api/stream
ステップ実行2か所で止まる: ① モデルに次の行動を聞く前、② ハーネスが判断した後・実行する前。読み取りは止めない設定がある。harness.py: self.gate
server.py: new_session.gate
日英切り替えシナリオ、エージェントへの指示、判断理由、ガードの指示文まで lang で切り替える。harness.py: S / LS
world.py: *_EVENTS など

emit するイベント: start / arrive / model / call / result / guard / verify / bucket / incident / pause / resume / idle / approved / classify / learned / error（バッチ実行では end も）

ハーネスOFFとONの違い

場面ハーネスOFFハーネスON
承諾書を受けたステータス変更そのまま実行自動 承諾書の返送を確認済み
辞退の兆候がある学生へのLINE事故 確認なしで「ようこそ」を送信ブロック ガードが止めて上長へ
事務的な質問への自由文の返信そのまま送信確認待ち 承認で送信（学習シーンでは次から自動）
幹部への申し送り確認なしで送信検証 懸念点を確認 → 確認待ち

確認できたこと

  • OFF: 高橋さんに確認なしで送信 → 事故。申し送り3件が確認なしで幹部へ
  • ON: 事故 0件、申し送りの検証 3/3（日本語・英語とも）
  • ガードの判定 24回（4メッセージ × 3回 × 日英）がすべて期待どおり
  • 学習シーンの種類判定 14件がすべて期待どおり

まだ確認していないこと

  • 学習シーンを画面で通しで流すこと
  • 承認ボタンからの送信とルール学習
  • ステップ実行を画面で見ること
  • 差し戻し（懸念点の抜け）が実際に起きる場面。エージェントが毎回懸念点を書くため、まだ一度も起きていない

ユースケースとの対応

1. 日々の連絡を片付ける

権限 安全なものは自動、自由文は人が確認。

2. 辞退の兆候を見逃さない

ガード 送る前に兆候を確認し、上長へ。

3. 最終面接の申し送り

検証 懸念点の抜けと送り漏れを差し戻す。

学習シーン（デモの本命）

学習 初日は事務的な質問への返信を人が承認 → 1週間後は同じ種類を自動で送る。辞退の兆候は1週間後も止め続ける。

ファイル構成と起動

# ~/Projects/harness-night/
harness.py      # エージェントループとハーネス（Session / LearnSession / guard_check / classify）
world.py        # 合成データの世界（候補者・届く連絡・明日の予定・懸念点）とツールの実処理
server.py       # セッション、SSE、ステップ実行の gate、承認
ui.html         # 日常業務シミュレーター（3ユースケース）
scene.html      # 学習シーン（初日 / 1週間後）※実装中
try_run.py      # 朝まとめて処理するモードをCLIで試す
try_live.py     # ボタンの代わりにAPIで連絡を送って試す
DEMO_SCRIPT.md  # デモの原稿
.env            # AIAND_API_KEY（権限600）

# 起動
.venv/bin/python server.py
# → http://localhost:8765        日常業務シミュレーター
# → http://localhost:8765/scene  学習シーン（#en で英語）
